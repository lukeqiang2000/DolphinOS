# dolphin-files — DolphinOS 文件管理器

Rust + Slint 自研文件管理器，二进制名 `dolphin-files`。

## 功能

- 列出目录内容：目录在前，同类按名称不区分大小写升序；每项显示图标占位（📁/📄）、名称、文件大小（人类可读，1024 进位）。
- 隐藏文件开关：以 `.` 开头的文件/目录默认不显示，顶部导航栏勾选「隐藏文件」后显示。
- 导航：后退 / 前进 / 上级按钮，浏览器式历史栈（访问新目录清空前进栈）；顶部显示当前路径。
- 交互：单击选中（高亮），双击目录进入，双击文件调用 `xdg-open` 打开；打开失败时状态栏显示错误。
- 底部状态栏：显示条目数与当前路径（出错时显示错误信息）。
- 起始目录：命令行第一个参数，缺省为 `$HOME`。

## 用法

```sh
cargo run -p dolphin-files -- [起始路径]
# 或直接运行构建产物
dolphin-files ~/Documents
```

## 结构

- `src/logic.rs`：纯逻辑（`list_dir`、`NavState`、`format_size`、隐藏过滤与排序），含单元测试（临时目录做文件系统测试）。
- `src/main.rs`：Slint 窗口接线、导航回调、`xdg-open` 调用。
- `ui/app-window.slint`：界面（导航栏 + `ListView` 列表 + 状态栏）。

## 未做到的部分

- 无地址栏直接输入路径、无面包屑、无搜索、无排序方式切换（固定目录优先+名称序）。
- 无新建/删除/重命名/复制粘贴等文件操作，无右键菜单。
- 无文件类型图标区分（只有目录/文件两种占位字符）、无缩略图、无修改时间列（逻辑层已记录 `modified_unix`，界面未展示）。
- 无拖拽、无多选、无权限/符号链接的特殊处理。
