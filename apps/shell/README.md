dolphin-shell：DolphinOS 桌面 Shell 正式版（Slint + Rust），二进制名 `dolphin-shell`。

已实现：
- 28px 窄顶栏：只放找应用入口、状态占位图标与时钟（每秒刷新）。
- 板块网格桌面：常用应用（文件/浏览器/终端/设置）直接成卡，其余按板块（媒体/系统）顺序排列；启动命令优先同目录二进制、退回 PATH。
- 打开动画三档（取自共享设置）：翻转＝卡片横向缩放模拟绕竖轴翻转、翻到中点启动应用；弹入＝轻微放大回落；无动画＝直接启动。动画时长由 dolphin-config 的 AnimationMode 给出。
- 左上角找应用入口：文字显示约 3.5 秒后自动隐藏、悬停再显示；点开是搜索面板（按名称/exec 过滤），点结果即启动。
- 桌面位置记忆：卡片上的 ◀ ▶ 可调整顺序，顺序持久化到 `~/.config/dolphinos/desktop.toml`，下次启动按保存顺序排（新应用自动补齐、已删应用自动丢弃，逻辑在 src/logic.rs 并有单测）。
- 系统板块卡：设置 / 重启 / 关机（经 loginctl）。
- 多主题数据层皮肤：启动时读 dolphin-config 当前主题的 palette（配色 + 圆角 + 形状指数），四主题各不相同（Metro 直角、Pixel 大圆角等）。
